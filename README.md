# ADMS - Advanced Drone Management System

ドローン業務の総合的な支援システム

## 概要

ADMSは、ドローン運用に関わるあらゆる業務を一元管理するための統合プラットフォームです。機材管理から飛行ログ、行政申請まで、ドローンビジネスに必要な機能を包括的に提供します。

## 主要機能

| 機能 | 説明 |
|------|------|
| カタログ管理 | ドローン・周辺機器のカタログ作成・管理 |
| 機材管理 | 所有機材の登録・状態管理 |
| スタッフ管理 | パイロット・オペレーターの資格・稼働管理 |
| 飛行ログ | 飛行記録の作成・保存・分析 |
| メンテナンスログ | 点検・整備履歴の管理 |
| プロジェクト管理 | 案件・業務の進捗管理 |
| クライアント管理 | 顧客情報・取引履歴の管理 |
| 申請管理 | DIPS2.0 API連携による飛行申請の効率化 |
